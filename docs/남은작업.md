## 반드시 해야 하는 것 (1차예선 전)

### 1. 커밋 이력에서 데모 비밀번호 빼기 — 30분 🔴🔴

**깃헙 주소가 제출물이다.** 지금 그대로 올리면 데모 계정 비밀번호가 함께 공개된다.

```
supabase/seed/.ipynb_checkpoints/demo.local-checkpoint.sql   ← 커밋 8ca3dad
```

`.gitignore` 는 `supabase/seed/*.local.sql` 을 막고 있었지만 Jupyter 가 만든
`.ipynb_checkpoints/` 안의 **사본의 사본**은 그 규칙에 걸리지 않았다.
이름 규칙으로만 막으면 이런 식으로 샌다. `.ipynb_checkpoints/` 를 무시 목록에 넣어 뒀다.

아직 **원격이 없어 한 번도 푸시되지 않았다.** 지금 정리하면 유출 없이 끝난다.

```bash
# 1) 추적에서 뺀다 (파일은 디스크에 남는다)
git rm -r --cached --quiet $(git ls-files | grep ipynb_checkpoints)
git commit -m "Jupyter 자동 저장본을 추적에서 제외 — 비밀번호가 담긴 사본이 섞여 있었다"

# 2) 이력에서도 지운다. 첫 푸시 전에 해야 한다
git filter-branch --index-filter \
  'git rm -r --cached --ignore-unmatch -q "*ipynb_checkpoints*"' \
  --prune-empty -- --all
git reflog expire --expire=now --all && git gc --prune=now --aggressive

# 3) 확인 — 아무것도 안 나와야 한다
git log --all -S'<비밀번호>' --oneline
```

> 이력을 고치는 것이 부담스러우면 **비밀번호를 바꾸는 편이 확실하다.**
> Supabase 대시보드에서 16개 계정 비밀번호를 새로 정하고, `.env.local` 과
> 배포 환경변수의 `DEMO_ACCOUNT_PASSWORD` 를 함께 바꾼 뒤 시드를 다시 만든다.
> 어느 쪽이든 **푸시 전에** 끝내야 한다.

