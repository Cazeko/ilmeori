# 시연 영상 대본 — 「일머리」

`발표대본.md` 와 갈래가 다르다. 그쪽은 **장표를 넘기며 주장하는 말**이고,
이것은 **화면을 따라가며 보여 주는 말**이다. 둘이 같은 사실을 말하되 문장은
겹치지 않게 썼다 — 심사위원이 둘 다 보면 같은 말을 두 번 듣게 되므로.

---

## 이 대본이 걸고 있는 한 가지 수

**앞의 2/3 동안 인계 이야기를 한 마디도 하지 않는다.**

대화·문서·결재를 평범한 협업 기능으로만 보여 준다. 그러다 8장에서 인사발령이
뜨고, 9장에서 **지금까지 한 모든 일이 사실은 인계서를 쓰고 있었다는 것**이
드러난다. 시연에서 가장 크게 먹히는 순간은 새 기능을 보여 줄 때가 아니라,
**이미 본 것의 의미가 뒤집힐 때**다.

그래서 3~7장에서는 이런 말을 하지 않는다 — 「이게 나중에 인계서에 실립니다」.
한 번이라도 말하면 9장이 확인 사살이 되고, 안 말하면 반전이 된다.

> **한 줄 소개(네 곳에서 토씨까지 같다).**
> 평소 결재와 대화가 쌓이면, 근거가 붙은 한/글 결재문서와 법정 인계서가
> 저절로 나옵니다.

## 촬영 전 점검

- [ ] `npm run build && npm start` — **개발 서버로 찍지 않는다.** 개발 서버는
      화면을 처음 열 때 그 자리에서 컴파일하느라 최대 16초가 걸린다(실측).
      프로덕션 빌드에서는 같은 이동이 0.2~0.5초다.
- [ ] 김서연 계정으로 들어가 홈·보드·결재함·쪽지함을 **한 번씩 미리 연다.**
      클라이언트 캐시가 데워져 있어야 이동이 즉각적이다.
- [ ] 브라우저 창 1440×900, 배율 100%, 북마크바 숨김, 확장기능 끔.
- [ ] 알림 종의 숫자가 **2** 인지 확인(9장에서 화면에 잡힌다).
- [ ] 9장을 위해 **계정 전환** 위치를 손에 익혀 둔다(오른쪽 위).
- [ ] 마우스는 **천천히** 움직인다. 커서가 화면을 가로지르는 시간이 곧
      시청자가 다음 장면을 준비하는 시간이다.

**대본에 박아 둔 값은 촬영 날 화면과 대조한다.** 목업 데이터가 바뀌면 아래가
먼저 어긋난다. 화면과 다른 숫자를 말하는 순간 나머지 전부를 의심받는다.

| 대본에 적힌 것 | 어디서 확인 | 2026-08-25 기준 |
|---|---|---|
| 참여 중인 업무 **13건** | 홈 머리 줄 | ✓ |
| 가장 급한 건 **D+28** | 홈 히어로 | ✓ |
| 그 업무의 **4개 부서** | 카드·상세 | 교통정책과·대중교통과·트램건설추진단·전국체전추진단 |
| **한지우 · 7월 2일 16:20** | 문서 탭 「검토 중인 노선안」 | ✓ |
| 알림 종 **2** | 오른쪽 위 | ✓ |
| 인계 시연 대상 | 자원순환과 **박준호 → 이하람** | ✓ |

## 말투 규칙

이 대본이 「강연처럼」 들리는 이유는 내용이 아니라 **문장 길이**다.

- **한 문장은 한 호흡.** 45자를 넘기지 않는다. 넘으면 자른다.
- **질문 → 한 박자 → 답.** 「~하시죠?」로 열고, 쉬고, 「그래서 ~했습니다」로
  닫는다. 이 세 박자가 이 대본의 뼈대다.
- **숫자는 소리 나는 대로 읽는다.** 「D+28」은 「스물여덟 날 지났습니다」로,
  「166건」은 「백육십육 건」으로. 화면의 글자를 그대로 읽으면 자막을 소리 내어
  읽는 것처럼 들린다.
- **기능 이름을 주어로 쓰지 않는다.** 「멘션 기능을 제공합니다」가 아니라
  「골뱅이를 치면 뜹니다」. 시연은 기능 목록이 아니라 **사람이 겪는 일**이다.
- **「~할 수 있습니다」를 쓰지 않는다.** 가능성은 약속이고, 시연은 이미 벌어진
  일이어야 한다. 「됩니다」·「남습니다」·「나옵니다」로 끝낸다.

## 하지 않을 말

`PRODUCT.md` 가 정한 선이다. 시연에서 한 번 어기면 질의응답에서 무너진다.

| 말하면 안 되는 것 | 대신 |
|---|---|
| 「AI가 인계서를 써 줍니다」 | 「규칙이 고릅니다. 모델은 부르지 않습니다」 |
| 「온나라와 연동했습니다」 | 「온나라에 올릴 파일을 만들어 드립니다」 |
| 「실제로 도입되어 쓰이고 있습니다」 | 「지금 보시는 데이터는 전부 가상입니다」 |
| 「워드에서도 잘 열립니다」 | 워드는 실제로 열어 본 적이 없다. **말하지 않는다** |
| 「접근성을 준수했습니다」 | 「검토하고 취사선택했습니다」 |
